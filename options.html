同步 Kemono 收藏

💡 嘗試自動同步您在 Kemono 上的收藏創作者！已收藏的創作者會以 ⭐ 標記顯示在黑名單中
📡 首先嘗試使用 Kemono API 自動獲取，如果失敗會顯示手動同步選項
⚠️ 注意：由於 Kemono 的 API 限制，可能需要使用手動方式同步

📋 備用方案：手動同步收藏

⚠️ 當自動同步失敗時顯示此選項。如果自動同步正常工作，您不需要使用此功能。

手動步驟（由於 API 限制，需要手動操作）：

  1. 登入 Kemono：確保您已在瀏覽器中登入 Kemono 網站
  2. 前往匯出頁面：訪問 收藏匯出頁面
  3. 產生資料：點擊頁面上的「Export」按鈕
  4. 等待完成：等待 JSON 資料出現在頁面的文字框中
  5. 複製資料：選取並複製整個 JSON 內容
  6. 貼上處理：將 JSON 貼到下方文字框，然後點擊「處理 JSON 資料」
💡 提示：如果匯出頁面顯示空白或錯誤，請確認：
• 您已正確登入 Kemono 帳號
• 您的帳號確實有收藏的創作者
• 嘗試重新整理頁面後再次點擊 Export

顯示效果設定

控制黑名單和收藏的視覺效果顯示

🚫 黑名單顯示效果

關閉後，被黑名單的創作者將不會有任何視覺變化，但黑名單按鈕仍會顯示

⭐ 收藏顯示效果

關閉後，收藏的創作者將不會有任何視覺變化，但收藏按鈕仍會顯示

📋 文章頁面設定

啟用後，在 /posts 頁面中，被黑名單的創作者文章將完全隱藏，只顯示未被黑名單的項目

🌐 網站網域

Kemono／Coomer 更換網域時可在此修改。儲存非預設網域時，Chrome 會跳出權限確認；拒絕則不會儲存。 儲存成功後請重新整理已開啟的網站分頁。

可輸入完整 URL 或純網域，系統會自動正規化（例如 https://kemono.cr/ → kemono.cr）

懸停預覽設定

設定在縮圖上懸停時顯示大圖預覽的功能

🔧 基本設定

關閉後，將不會顯示懸停預覽

🎛️ 預覽觸發控制

與下方「切換模式」分開；切換圖片的 Alt+滾輪仍固定使用 Alt

⌨️ 預覽控制快速鍵

若選「懸停即預覽，按著快速鍵暫時停用」且切圖也用 Alt+滾輪，建議將此快速鍵改為 Ctrl 或 Shift，避免衝突

🔄 切換模式

選擇切換預覽圖片的方式

📏 預覽尺寸

設定預覽圖的最大寬度（200-1200px）

⚡ 預載入設定

設定預先載入接下來的圖片數量，以便滾輪切換時不用等待。設為 0 則停用預載入功能（0-20）

🚦 請求速率限制

限制 API 查詢和預覽圖預載的請求速率，避免過快發送請求。如果超過此速率，請求會自動排隊等待（1-100）

🧾 日誌等級

控制主控台輸出的詳細程度。等級越低輸出越少；變更後會立即套用到已開啟的網站分頁。
